# VoteSphere — Polling & Voting App

A modern animated polling and voting application built with **HTML5, CSS3 and vanilla JavaScript**.

## Features
- Create polls with 2–6 options
- One vote per poll per browser
- Live percentage result bars
- Multiple simultaneous polls
- LocalStorage persistence
- Responsive mobile/desktop layout
- Animated 3D-style hero and glass cards
- Light/dark theme toggle
- Reset demo data

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Stack
HTML5 • CSS3 • JavaScript • LocalStorage
